# Book Tracker

A book tracker where you keep a list of books you want to read, are reading, or have finished.

**Live site:**  https://sonarosedevasia.github.io/book-tracker/

## Features
- Add a book with title, author and status (title and author required)
- Newest books appear first
- Search by title or author (ignores capital letters)
- Change a book's status from the list
- Delete a book, with a confirmation
- Counts for total, finished, reading and to read
- Data is saved in the browser with localStorage
- Works on laptop and phone

## How to run
Download the files and open index.html in a browser. No installation needed.

## Built with
HTML, CSS and JavaScript, built step by step with Antigravity (AI) and tested by me.
